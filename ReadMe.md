# 演出モードとEditor まとめ

Compute Shader による GPU パーティクル（最大 10,240 粒）をベースに、従来の 3D 描画（モード0）と画面空間の環境演出（モード1〜3）、リアルタイム調整用 ImGui Editor を統合したシステムです。

## 1. 演出モードと操作一覧

数字キー（`1`〜`4`）または ImGui の `Scene Mode` から4種類の演出をリアルタイムに切り替えられます。

| モード | 名称 | 描画空間・対象 | 演出内容と多層構造 |
|---|---|---|---|
| **0** | **Default** | 3D空間（モデル＋粒） | ビルボード＋加速フィールドによる従来の3Dパーティクル |

| **1** | **Desert（砂漠）** | 画面空間（背景＋粒） | 巨大砂煙(16%)・砂塵の帯(24%)・飛翔砂粒(34%)・地面の堆積砂(26%)の4層構造 |

| **2** | **Spring Petals（花びら）** | 画面空間（背景＋粒） | 遠景の陽光ボケ光(16%)・舞う花びら(56%)・地面の花びら絨毯(28%)の3層構造 |

| **3** | **Night Storm（嵐の夜）** | 画面空間（背景＋粒） | 低空の霧(10%)・奥の霧雨(35%)・豪雨(55%)＋着地時の水しぶき・波紋・稲妻 |

### インタラクション操作
* **`1` 〜 `4` キー**：演出モード切替（切替時に全パーティクルを画面全体へ再配置）
* **マウス移動 / 左クリック長押し**：気流干渉・障害物判定（左クリックで影響力が約2.5〜3倍に増幅）
* **`Space` キー長押し（特殊演出）**：
  * **砂漠**：地面の砂まで吸い上げる漏斗状の巨大竜巻
  * **花びら**：積もった花びらが一斉に舞い上がる花吹雪のつむじ風
  * **嵐の夜**：暴風竜巻（ウォータースパウト）＋空を裂く稲妻と激しい稲光フラッシュ

## 2. ImGui Editor と JSON ホットリロード

モード1〜3の選択中、ImGui の `Particle` タブから演出パラメータをリアルタイムに編集できます。

* **主な編集項目（`ParticlePreset`）**：
  粒数（`count`）、背景色（`background`）、粒色グラデーション（`colorA` / `colorB`）
  サイズ（`sizeMin/Max`）、寿命（`lifeMin/Max`）、速度（`speedMin/Max`）、風・乱流（`wind` / `turbulence`）、縦横比（`stretch`）
  * マウス影響半径・力（`mouseRadius` / `mouseForce`）、ブレンド切替（`additive`：加算 / 通常$\alpha$）
* **JSON 永続化とホットリロード**：
  * `Save Presets` / `Load Presets` で `particle_presets.json` へ保存・読込（初回起動時は既定値で自動生成）。
  * **ホットリロード**：約0.5秒（30フレーム）ごとにファイルの更新日時を監視し、外部エディタで JSON を書き換えて保存すると即座に画面へ反映されます。

## 3. 演出と Editor でこだわったポイント

* **多層構造（レイヤー設計）による奥行きと空気感の表現**
  単一のパーティクルをただ降らせる・飛ばすのではなく、粒のインデックス割合で役割を分担させました。遠景のボケや霧、中景の帯、前景の粒、さらに「地面に積もる砂や花びらの絨毯」「雨粒が作る水たまりの波紋」まで組み合わせることで、画面全体に奥行きと環境としてのリアリティを持たせています。
* **触って楽しいインタラクティブな手触り**
  * **砂漠**：マウスを障害物に見立てた回り込み気流と後流の渦を計算し、地面に積もった砂の上を素早く動かすと砂が舞い散ります。
  * **花びら**：落下中の回転に加えて横幅を周期変化させることで「3D空間でひらひら裏返る動き」を疑似表現し、積もった絨毯からもマウスや竜巻で舞い上がります。
  * **嵐の夜**：マウス周囲の円盤に雨が当たると水しぶきが弾け、`Space` キー長押しで雷撃と背景フラッシュが連動する迫力ある演出へ変化します。
* **調整のしやすさを追求した Editor 体験**
  ビルドし直すことなく ImGui 上で色や風速を直感的に詰められるだけでなく、外部テキストエディタからの JSON 直接編集にも対応するホットリロードを実装し、試行錯誤のサイクルを高速化しました。

## 4. プログラムでこだわったポイント

* **Compute Shader による完全 GPU 完結パイプライン**
  粒の生成（`Emit`）、物理演算・気流ノイズ・マウス反応（`Step`）、最終的なワールド・WVP 行列の計算までをすべて GPU（Compute Shader）上で並列実行しています。CPU は毎フレーム定数バッファを更新するのみで、1回の `DrawInstanced` で 10,240 粒を高速に描画しています。
* **構造体の再利用と `pad` によるデータパッキング**
  GPU バッファの肥大化を防ぐため、`ParticleForGPU` の既存フィールドを画面空間演出用に有効活用しています。
  * `pad` の**整数部**に描画種別（煙・砂粒・花びら・雨・波紋・霧・稲妻）、**小数部**に粒固有の乱数シードをエンコードして Vertex Shader から Pixel Shader へ伝達。
  * `position.z` に着地ラインや回転角、`velocity.z` に地面への堆積状態フラグを格納し、メモリ効率と表現の幅を両立しました。
* **Pixel Shader によるプロシージャル形状・質感生成**
  モード1〜3ではテクスチャを増やさず `white1x1` のみを使用し、Pixel Shader 内の UV 座標計算と FBM ノイズ・距離関数によって、砂煙の濃淡、桜の花びら先端の切れ込み、雨筋、波紋リング、稲妻の閃光をリアルタイム生成しています。
* **安全性を重視した堅牢な設計（ロバストネス）**
  * C++ 側と HLSL 側の定数バッファ（`ParticleCSConstant`）を16バイト境界で厳密にアライメント一致。
  * ホットリロード時の JSON 編集途中の構文エラーを `try-catch` で安全に無視し、不正値（寿命0など）もクランプ処理してクラッシュを防止。
  * ImGui 操作中（`WantCaptureMouse` / `WantCaptureKeyboard`）の入力遮断や、自前保存直後の二重リロード防止、`SrvManager` での UAV/SRV 解放漏れ対策を徹底しています。
